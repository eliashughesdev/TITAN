# ADR-003 - Ponches permanece en Python

## Estado

Accepted.

## Decisión

La integración biométrica continuará como servicio Python.

## Razón

El ecosistema ZKTeco y las integraciones actuales están
implementadas en Python y una reescritura inmediata no
aporta valor suficiente.

## Consecuencias

TitanMDM será la plataforma principal.

Ponches será consumido mediante una API interna autenticada.
